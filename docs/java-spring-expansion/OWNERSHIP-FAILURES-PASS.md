# Java ownership and Spring rollback pass

This review curriculum has 256 Java articles in 10 hubs and 53 Spring & Spring Boot articles in 10 separate hubs. Seven new Java 8 lessons cover reference-identity maps, TreeSet comparator collisions, EnumMap ordering and nullable values, interrupt-status consumption, CompletableFuture allOf failure, CompletableFuture observation versus recovery, and Files.walk resource ownership. Each new Java article has a runnable fixture, checked output, failure boundary, cost statement and links to existing lessons. The collection cases live under Java Collections; cancellation, futures and file ownership live under Advanced Java.

One new Spring Data & Transactions lesson checks default rollback for an unchecked failure, commit after a checked IOException, and explicit rollbackFor on that checked exception. Its complete JUnit/H2 test is in the downloadable Spring source kit. The fixture is local to one data source. It does not establish target-database behavior or rollback of broker, file or HTTP side effects. Spring & Spring Boot stays one separate subject and does not appear as a Java module; cross-subject links connect exception and transaction concepts.
