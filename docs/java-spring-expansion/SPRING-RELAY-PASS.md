OutboxRelayFlowTest adds seven deterministic H2 checks. A producer request and outbox row commit or roll back together. A worker claims a due row with a token and lease, invokes the local consumer, and acknowledges only while it owns the lease. The consumer records the event ID and stock change in one transaction; a repeated event does not subtract stock twice, and a failed stock mutation rolls its event marker back. Failed attempts wait until their stored due time, and a three-failure budget moves a row to DEAD. Expiry allows a replacement claim while rejecting the old worker's acknowledgement. The retry update is one conditional SQL statement so failure count, state and due time change together. The checks use logical time and direct calls, not a background scheduler.
