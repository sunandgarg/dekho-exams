BootRelaySettingsTest starts a small non-web Spring Boot context. Three checks assert that a command-line batch-size value overrides the application default, an explicit 450ms value binds to Duration.ofMillis(450), and an effective batch size of zero prevents startup under @Min(1). This is a real Boot startup path for defaults and command-line arguments. It does not load an application.properties file, set a real operating-system environment variable, read a mounted secret, or install the relay in ReceiptApplication.

SchemaEvolutionContractTest uses direct H2 SQL. One test adds nullable tenant_id, lets an old writer omit it, and backfills two rows with a fixture-only legacy value. The other backfills before setting NOT NULL, then checks that the old writer fails and a new writer supplying tenant_id succeeds. The tests do not use Flyway or Liquibase, a schema history table, target-database DDL, a large table, concurrent deployment or a real tenant registry. The legacy value is a local fixture rule, not a production ownership decision.
