# Collection and web-contract pass

The review curriculum now has 249 Java articles in 10 hubs and 52 Spring & Spring Boot articles in 10 separate hubs. This pass adds eight Java 8 collection lessons: `ListIterator` edits, `checkedList` at a raw boundary, `retainAll` multiplicity, contiguous subsequence search, `Map.merge` removal, `computeIfAbsent` null behavior, `PriorityQueue` tie policy and `removeIf` predicate ownership. The linked-list pages remain in Java Collections; map and queue pages are linked from their existing subject pages. Each new Java page has a runnable program, a checked output, costs, failure cases and related lessons.

Two new Spring Web APIs lessons cover request `Content-Type` versus `Accept` (415 versus 406), and cascading validation of a nested request field. Their complete MockMvc/JUnit tests are in the downloadable Spring source kit. Spring remains a separate subject: the Java curriculum contains no Spring module, while deliberate cross-subject links connect concepts such as map mutation and transactions.

Research began with the requested Oracle Java 8 LinkedList reference, GeeksforGeeks Java overview, W3Schools LinkedList, BeginnersBook LinkedList and CodingNomads linked-list page, in that order. Oracle's `List`, `Collections`, `Map` and `PriorityQueue` contracts and the Spring Framework's request-mapping and `@RequestBody` references resolved the precise behavior used here. These sites informed API checks and page selection. Public explanations and programs were newly written for AI Trove; third-party prose and examples were not transplanted by changing values.
