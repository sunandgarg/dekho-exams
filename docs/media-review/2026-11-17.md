# Public media review — 17 November 2026

Completed live verification on 18 November 2026.

## Scope and evidence

- Inventoried 5,957 question-image URLs (5,833 distinct files) and 1,900 PDF editions across eight exams.
- Checked archive images using normal/dark composites, optical text recognition, and full-resolution amplified pale-ink views. Confirmed faint marks can be missed by ordinary OCR. Ambiguous content was withheld; diagrams and answer keys were not reconstructed or guessed.
- Inspected 23,678 distinct PDF image objects: 23,635 could be rasterized, while 43 malformed or incompatible mask objects were withheld. Screened all original documents for visible branding text, external annotation links, inline images, and full-page scans.
- Reviewed other site raster graphics separately. The live verification compared all 69 other raster/vector assets, including math glyph sheets, to the reviewed files.
- The compressed edition ledger stores original document SHA-256 hashes, page counts, unapproved image xrefs and replacement SHA-256 hashes. It contains audit data, not instructions.

## Enforcement

The diagram and PDF manifests control delivery before shared cache lookup. Only recorded byte versions can be served. English/Hindi readers, options, solutions, print editions and mock generation use the same diagram policy. Unknown/direct/encoded media paths cannot bypass the review. A changed object fails closed, and a stale partial-download validator causes a full restart.

The frontend and AWS preview Workers both enforce this policy. Newly revised files currently live on the existing 1 GB Mumbai app server, behind authenticated origin access and Cloudflare caching. Safe unchanged PDFs and original archive figures continue to use private S3. The publishing AWS CLI login expired; no replacement PDFs were uploaded to S3 during this release. See the Lightsail deployment README for the verified S3 cutover procedure. No infrastructure plan was upgraded.

## Limits

Automated scans and visual review can miss extremely faint or unfamiliar marks. This review is not a guarantee of detecting every possible watermark, nor an academic correctness review. No answers were guessed. Unverified drawings stay visibly pending; twelve scanned editions need a clean source. Sitemap acceptance does not guarantee indexing, ranking or traffic.
